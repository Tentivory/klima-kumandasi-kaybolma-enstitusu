# Klima Kumandası Kaybolma Enstitüsü

**Resmî kısa ad:** KKKE  
**Kuruluş yılı:** 2026 (koltuk minderi keşfedildikten hemen sonra)  
**Ciddiyet katsayısı:** 12/10 (ISO 31415-Klima)  
**Durum:** Çalışır. Kumanda hâlâ yok.

---

## 1. Misyon Beyannamesi

Bu yazılım, yazın 37 derecede evin içinde duran bir vatandaşın klima kumandasının *kesin olarak* koltuk ile duvar arasındaki karanlık koridora düştüğünü bilimsel olarak varsayar.

Enstitü şunları yapar:

1. Kayıp bildirimi alır.
2. Üç hipotez üretir (minder altı, kedi suçu, "ben az önce elime aldım" yanılsaması).
3. Ulusal seferberlik tutanağı basar.
4. Kumandayı **bulmaz**. Bu bir özelliktir.

Kumandayı bulmak Enstitü'nün görevi değildir. Enstitü'nün görevi *arandığını belgelemektir*.

## 2. Kurulum

```bash
git clone https://github.com/Tentivory/klima-kumandasi-kaybolma-enstitusu.git
cd klima-kumandasi-kaybolma-enstitusu
python3 enstitu.py
```

Bağımlılık yoktur. Python 3 yeter. Klima da yeter ama o ayrı bütçe kalemidir.

## 3. Kullanım

```text
python3 enstitu.py
python3 enstitu.py --oda salon --siddet 9
python3 enstitu.py --gizli
```

`--gizli` bayrağı Enstitü tüzüğünün dipnotunu açar. Dipnot akademikdir. Siyasi değildir. (Siyasidir ama inkâr edilecek kadar küçüktür.)

## 4. Bilimsel Yöntem

| Hipotez | Olasılık | Açıklama |
|---|---|---|
| H1 Minder Altı | %41 | Koltuk fiziğinin evrensel sabiti |
| H2 Kedi Taşıması | %33 | Suçlu bakış kanıttır |
| H3 El Yanılsaması | %26 | "Az önce buradaydı" sendromu |

Hiçbir hipotez doğrulanmaz. Doğrulama, serinlik duygusunu zayıflatır.

## 5. Katkı

Pull request açmadan önce kumandanızı bulun. Bulamazsanız PR'nız kabul edilir.

## 6. Lisans
